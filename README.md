# DnevnikSdelok


(!!!ПОКА ЧТО В РАЗРАБОТКЕ!!!)

Локальный журнал исполнений для Windows. Первая версия подключается к Binance через read-only ключи, созданные в Vataga Crypto.

## Запуск из исходного кода

Требуется .NET 10 SDK:

```powershell
dotnet run --project DnevnikSdelok.csproj
```

Чтобы быстрее тестировать правки, откройте в VS Code корневую папку этого GitHub-репозитория и нажмите **F5**, выбрав конфигурацию «DnevnikSdelok: запуск из исходников». Она автоматически соберёт только Debug-версию и запустит приложение; полный установочный `.exe` при изменении кода собирать не нужно. Если VS Code попросит установить C#-отладчик, установите расширение C# от Microsoft.

API-подключения не хранятся в выходной папке сборки: при запуске из исходников и готового `.exe` приложение использует одну базу `%LOCALAPPDATA%\DnevnikSdelok\journal.sqlite3`. Поэтому обычная сборка или изменение программы не требует добавлять API-ключи повторно. Не удаляйте эту базу и не очищайте данные приложения. Перед сменой компьютера или Windows сохраните резервную копию базы, но учтите: зашифрованные API-ключи привязаны к этому пользователю Windows, а саму копию желательно хранить в защищённом месте.

Перед запуском версии через F5 закройте уже запущенный `.exe`: обе версии используют одну базу, а одновременно открытые копии будут независимо синхронизировать биржу.

Для проверки интерфейса без автоматического обращения к биржам запустите собранный Debug-файл с аргументом `--offline`:

```powershell
.\bin\Debug\net10.0-windows\DnevnikSdelok.exe --offline
```

Для сборки автономной Windows x64-версии:

```powershell
dotnet publish DnevnikSdelok.csproj -c Release -r win-x64 --self-contained true
```

Для встроенного графика нужны Microsoft Edge WebView2 Runtime и подключение к интернету. В Windows 11 и большинстве актуальных установок Windows 10 WebView2 Runtime уже есть.

## Подключение

В Vataga создайте **два API-ключа только для чтения**: отдельный для Binance Spot и отдельный для Binance USDⓈ-M Futures. Не включайте торговлю или вывод средств. Откройте **Настройки → Действия → Подключить API**, выберите рынок, введите ключ и секрет. Программа проверит соединение с официальным API Binance, прежде чем сохранить ключ.

После запуска приложение синхронизирует подключения; вручную обновить список можно через **Настройки → Действия → Обновить список сделок**. Пока программа открыта, синхронизация повторяется каждые 15 минут. В журнале отображаются исполнения, их можно сортировать по столбцам, фильтровать по периоду/подключению и искать по паре.

## Главный экран и настройки

В приложении есть вкладки «Мои сделки» и «Сводка». Во вкладке «Мои сделки» показана одна строка на позицию, а не отдельная строка на каждое биржевое исполнение; полный список входов и выходов позиции доступен в карточке по нажатию на тикер. Новые и недавно закрытые позиции по умолчанию находятся сверху. Таблицу можно сортировать, фильтровать и искать. Выбранная строка остаётся подсвеченной и после сворачивания карточки позиции клавишей Escape или повторным нажатием на тикер. Колонки берутся только из списка включённых в настройках — остальные свойства модели в таблицу не добавляются. Вкладка «Сводка» содержит виджеты кумулятивной прибыли, винрейта, числа исполнений, статуса синхронизации и графика прибыли.

По умолчанию используется чёрно-зелёная палитра; цвета и виджеты сводки можно настраивать. Карточки сводки можно упорядочивать, закреплять и менять в размере; таблица сделок занимает всю свою вкладку и не является перемещаемым или изменяемым виджетом. Настройки подключения API, обновления, CSV-экспорта и резервного копирования находятся в разделе «Настройки».

В настройках колонок можно выбрать отображаемые поля и их ширину; порядок также меняется перетаскиванием заголовков таблицы. По умолчанию включены: тикер, сторона, дата и время входа, длительность сделки, причины входа, категория, рейтинг, процент, прибыль, комиссия, фандинг и «Плечо от депозита». Последнее считается как номинал входа, делённый на баланс счёта в USDT в момент входа, и выводится множителем (`2,5x`), а не процентом от результата. Время входа и длительность рассчитываются по связанным исполнениям, включая частичные входы и выходы. Для спота расчёт выполняется только когда снимки баланса согласуются с загруженными исполнениями; Binance предоставляет исторические дневные снимки за ограниченный период. Для фьючерсов баланс восстанавливается по истории изменений кошелька. Если точный баланс восстановить нельзя, показывается «—». Эти значения также включаются в CSV-экспорт. Причины, категорию, рейтинг и дополнительные заметки можно редактировать непосредственно в журнале; они сохраняются локально вместе с исполнением. Кнопка сброса возвращает начальные настройки экрана и колонок.

Нажмите на тикер, чтобы развернуть карточку позиции под строкой. Встроенный TradingView Lightweight Charts показывает свечи Binance Spot или USDT-фьючерса; библиотека графика загружается из CDN, а публичные рыночные данные — напрямую с Binance, без API-ключа. Страница графика создаётся один раз, поэтому переключение между позициями не перезагружает её. Отметки исполнений выполнены цветными шевронами и показывают только сделки выбранной позиции. Пунктирные уровни средних цен начинаются у соответствующих входа и выхода и продолжаются вправо до конца графика. Для закрытой позиции показывается процент изменения и итоговый P&L. Щёлкните правой кнопкой мыши по графику, чтобы включить или отключить сетку; настройка общая для всех графиков и сохраняется. Доступны таймфреймы от 1 секунды до 4 часов: секундные свечи формируются из агрегированных сделок Binance и имеют ограниченную глубину истории; остальные загружаются как свечи биржи. Данные и загрузка требуют интернета и могут ограничиваться доступностью API Binance. График поддерживает масштабирование и прокрутку; полный набор инструментов рисования и индикаторов большого TradingView здесь не предоставляется. Кнопка «Снимок PNG» сохраняет текущий вид графика в файл. Справа находятся описание, вывод, ссылка на видео, несколько изображений и список исполнений этой позиции с типами ордеров Binance. Нажмите на изображение, чтобы открыть его на весь экран; масштаб меняется через Ctrl + колесо мыши, выход — Escape. Если в старых данных отсутствует ID ордера, приложение получает его при открытии карточки с помощью API-ключа только для чтения; тип ордера сохраняется локально. Часовой пояс в настройках применяется к времени журнала и графика.

## Данные и резервные копии

- База SQLite: `%LOCALAPPDATA%\DnevnikSdelok\journal.sqlite3`.
- API-ключи зашифрованы средствами Windows DPAPI для текущего пользователя.
- CSV экспортирует историю исполнений, заметки и комиссии; API-секреты в него не включаются. Экспорт доступен через **Настройки → Действия → Экспорт CSV**.
- ZIP-резервная копия содержит базу SQLite и папку со скриншотами. Сохраняйте ZIP на другой диск или в папку, синхронизируемую Google Drive/OneDrive. Прямого подключения к облачному аккаунту пока нет.
- Для восстановления закройте приложение и распакуйте содержимое ZIP в `%LOCALAPPDATA%\DnevnikSdelok`, заменив базу; затем запустите приложение. На другом компьютере DPAPI-ключи могут потребовать повторного ввода.
- При переносе копии на другой компьютер API-ключи может потребоваться добавить заново.

## Ограничения первой версии

- Поддерживается только Vataga → Binance → Spot и USDT-M Futures. Обратные контракты, Bybit, MetaBroker и Tiger пока не подключены.
- Для Spot Binance предоставляет историю по одной торговой паре за запрос. Поэтому первая и последующие проверки проходят по активным парам и могут занять несколько минут; частота запросов ограничена.
- Автоматическая история загружается примерно за последние 90 дней. Более старые архивы Binance пока не загружаются.
- Futures P&L берётся из реализованного P&L биржи. Spot P&L оценивается по средней цене покупки, только для известных покупок в загруженной истории и USDT-пар. Комиссии в отдельном токене, например BNB, не конвертируются в USDT, поэтому отображаемый P&L может их не учитывать.
- Win rate рассчитывается по закрытым позициям фьючерсов и полностью закрытым позициям Spot с известной себестоимостью. Это аналитика дневника, а не налоговый расчёт.
- Теги, вложения, подключения других брокеров и интеграция с Google Drive напрямую будут добавляться отдельно.
